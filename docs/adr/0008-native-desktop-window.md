# Open the interface in a native window without changing the HTTP boundary

Everyday use should not require a terminal, a browser tab, or knowledge of the loopback port. `library app` opens the existing React interface in a native macOS window via pywebview (WebKit). It keeps the interface as it is. We chose this over a port-free bridge or a separate desktop frontend because the fixed loopback address is part of the product: citation links embed it, the Codex skills and browser bookmarks use it, and the Host/Origin/CSRF protections are built on it. The window loads that same address, so links, security checks, and API contracts are unchanged, and `library serve` remains a supported browser path.

The window owns at most one server. If a Reading Room server for the same library already answers at the address (for example the optional login service), the window reuses it and leaves it running on close. If it answers for a different library, or an unrelated program holds the port, the window stops with an explanation instead of guessing. Otherwise it runs uvicorn on a background thread (Cocoa needs the main thread) and stops it on close, so the intake worker's normal shutdown runs. The web view is not private, so the appearance preference and session snapshots persist like a browser's.

`Reading Room.app` at the checkout root is a convenience launcher, generated by setup from reviewable sources in `macos/` rather than committed as a binary. It is an AppleScript applet because macOS attributes privacy access to an applet bundle and can ask for permission to open a checkout or library inside `~/Documents`; a shell-script executable is attributed to `/bin/sh` and silently denied. The build is skipped while its sources are unchanged so a granted permission is not invalidated by a new ad hoc signature.

This remains a source installation (ADR 0006). The window's Dock and menu-bar identity come from the Python runtime, not the launcher; a packaged, signed application is possible future work and would revisit distribution, signing, and where checkout-local state lives.
